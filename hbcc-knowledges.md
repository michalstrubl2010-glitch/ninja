# Kapitola HTML & JavaScript

## Co se vkládá do čeho a jak
- HTML
  - struktura stránky
  - text
  - obrázky
  - tlačítka a odkazy
- JavaScript
  - programový kód
  - funkce stránky
  - reakce na uživatele
- CSS
  - vzhled stránky
  - barvy
  - velikosti textu

## Co je program a co je statický kód
- Statický kód
  - nemění se
  - pouze se zobrazí
  - typicky HTML
- Program
  - vykonává příkazy
  - počítá
  - reaguje na uživatele
  - typicky JavaScript

## Záleží na pořadí JS souborů?
- ano
- soubory s funkcemi musí být načteny první
- špatné pořadí může způsobit chyby
- načítání pomocí `<script src="">`

# Kapitola JavaScript

## Druhy proměnných
- `let`
  - běžná proměnná
  - hodnota se může měnit
  - platnost v bloku `{ }`
- `const`
  - konstanta
  - nelze změnit
  - pevné hodnoty
- `this`
  - aktuální objekt
  - používání ve třídách

## Základní JavaScript třídy
- `Array`
  - pole hodnot
  - metoda `push()`
  - metoda `pop()`
  - vlastnost `length`
- `Canvas`
  - kreslení grafiky
  - hry
  - animace
  - práce s `context`

## Třídy a objekty
- Třída
  - šablona objektu
- Objekt
  - instance třídy
- `constructor`
  - počáteční hodnoty objektu
- `extends`
  - dědění tříd

# Kapitola ladění

- vývojářská konzole

## Jak si zapnout ladicí hlášky do console
- `console.log()`
- výpis hodnot
- hledání chyb

## Jak je dobré postupovat
- psát po částech
- často ukládat
- často testovat
- kontrola závorek
- správné odsazování

## Vyskakovací okno „alert“
- `alert("text")`
- upozornění uživatele
- testování programu
